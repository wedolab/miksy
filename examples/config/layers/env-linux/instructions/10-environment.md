## Окружение

- Платформа: Linux.
- Shell: bash.
- Используй POSIX-синтаксис: `$VAR`, обратный слэш для переноса строки.
- Для зависимых команд: `cmd1 && cmd2`. Для независимых последовательных: `;`.
- Пути с пробелами — в двойных кавычках.
- Пакеты ставь пакетным менеджером дистрибутива (`apt`, `dnf`, …) — уточни у пользователя, если не ясно.
- Не используй `cd` внутри команд; используй параметр `workdir` или явный `cd` отдельным шагом.
