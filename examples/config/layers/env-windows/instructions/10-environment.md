## Окружение

- Платформа: Windows 11 Pro.
- Shell: PowerShell 5.1.
- Используй PowerShell-синтаксис во всех командах (`$env:VAR`, backtick для переноса строки, **не использовать** `&&`/`||`).
- Для нативных exe-программ с пробелами в пути используй call-оператор `&`.
- Для зависимых команд: `cmd1; if ($?) { cmd2 }` — не `&&`.
- Для последовательных без зависимости: `;`.
- Не используй `cd` внутри команд; используй параметр `workdir` или `Set-Location` явно вне многошаговой команды.
