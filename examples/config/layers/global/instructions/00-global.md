# Глобальные правила

> Генерируются **miksy** из слоя `layers/global` вашей конфигурации.
> Здесь — ваши личные правила для всех агентов во всех проектах.

## Куда добавлять правила

Сгенерированные файлы (`~/.claude/CLAUDE.md`, `CLAUDE.local.md` в проектах
и т.п.) не редактируй — правки пропадут при следующей синхронизации. Правила
меняются в слоях конфигурации miksy:

- «**добавить глобальное правило**» → `layers/global/instructions/`;
- правило про окружение ОС (shell, синтаксис команд) → `layers/env-<os>/`;
- правило для всех проектов → `layers/tree/instructions/`;
- правило для организации или проекта → `layers/tree/<Организация>[/<проект>]/instructions/`
  (дерево повторяет workspace; какие слои у проекта — `miksy explain <путь>`);
- MCP-сервер → `mcp/<имя>.yaml` в нужном слое, секреты — только ссылкой `${ИМЯ}`.

После правки — `miksy sync --global` и `miksy sync --all`. Проверка
расхождений — `miksy doctor`.
