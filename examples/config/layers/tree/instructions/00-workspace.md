# Workspace — общие правила для всех проектов

> Этот текст miksy кладёт в каждый проект workspace.

## Context7

Используй MCP-сервер Context7 первым для любого поиска по библиотекам,
фреймворкам и документации — перед web-поиском.

## Git

- Никогда не коммить без явного запроса пользователя.
- Секреты (токены, пароли, ключи) никогда не коммить.
- Конфиги агентов, которые раскладывает miksy, лежат в проектах вне git
  (`CLAUDE.local.md`, локальные настройки агентов). Не редактируй их и не
  коммить — источник в слоях miksy.

## MCP

MCP-серверы подключает miksy по слоям: workspace → организация → проект. Новый сервер —
файлом `mcp/<имя>.yaml` в нужном слое конфигурации miksy, не командой агента
(`claude mcp add` и т. п.); секреты — только ссылкой `${ИМЯ}`.
