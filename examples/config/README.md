# Моя конфигурация miksy

Личная часть miksy: слои с правилами, MCP и skills для ваших агентов и
проектов. Создана командой `miksy setup` из примера движка — дальше меняйте
как угодно. Как устроены слои и как пользоваться — README движка.

| Что | Где |
|---|---|
| глобальные слои, префикс своих skills, программы машины | `map.yaml` |
| ваши правила для всех агентов везде | `layers/global/` (+ `env-windows`, `env-macos`, `env-linux`) |
| правила, MCP и skills для проектов | `layers/tree/` — дерево повторяет workspace |
| настройки этой машины, секреты, учёт, бэкапы | `local/` (не в git) |

Примеры слоя организации — цель-группа, доверие, MCP с секретами (stdio и HTTP) — в
`examples/extra` движка: скопируйте нужное сюда.

Чтобы переносить конфигурацию между машинами, заведите для этого каталога
**приватный** git-репо. `local/` (настройки машины, секреты, учёт) в git не
попадает.
