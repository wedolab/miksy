# Antigravity

Где Antigravity получает настройки от miksy (правила, skills, MCP-серверы) и как подключить его в Zed.

| Где запускаете | Настройки miksy | Что сделать |
|---|---|---|
| `agy` в терминале | видит | ничего |
| IDE Antigravity | видит | ничего |
| Zed — своя запись `agy acp` | видит | один раз добавить запись — [ниже](#antigravity-в-zed) |
| Zed — расширение «Google Antigravity» из каталога агентов | **не видит** | не пользуйтесь им с miksy |

## Antigravity в Zed

Подключайте Antigravity в Zed своей записью, которая запускает `agy acp` — сам CLI `agy` в роли агента Zed. Тогда
агент получает всё, что разложил miksy, как в терминале. Нужен `agy` 1.5.0 или новее (`agy --version`; обновить —
`agy update`).

1. Узнайте путь к `agy`: `where agy` (Windows) или `which agy` (macOS, Linux).
2. Zed → `Ctrl+,` (macOS — `Cmd+,`), в `settings.json` внутрь внешних `{ }` добавьте (путь — свой; в Windows обратные
   косые черты удваиваются). Есть уже `agent_servers` — добавьте внутрь только `"Antigravity": {…}`:

   ```json
   "agent_servers": {
     "Antigravity": {
       "type": "custom",
       "command": "C:\\Users\\<имя>\\AppData\\Local\\agy\\bin\\agy.exe",
       "args": ["acp"]
     }
   },
   ```

3. Agent Panel → `+` → **Antigravity**. Вход — тот же, что в `agy`.

- MCP-серверы проекта на Windows иногда видны только со второго сообщения в беседе: Antigravity запускает их не сразу.

## Почему не расширение из каталога Zed

«Google Antigravity» в каталоге агентов Zed — другая программа (`antigravity-acp`), не `agy`. Она не читает правила —
ни проекта, ни даже глобальные — и MCP-серверы проекта; берёт только глобальный MCP, а его miksy пишет из глобального
слоя. Поэтому агент в ней не знает ваших правил (например, запретов) и не видит инструментов проекта. Со стороны miksy
это не исправить: писать для неё некуда. Проверено на версиях 1.4.5 и 1.5.0 (2026-11).

Расширение можно оставить установленным — следить за обновлениями. Когда оно начнёт читать настройки, это появится в
[CHANGELOG](../CHANGELOG.md) и здесь.
